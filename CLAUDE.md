# Group Games: notes for AI assistants

A static website of 72 captioned animated films teaching physical group games. No build step: `site/` is the website and is served as-is. Live at https://mteyra.github.io/group-games/.

## Where to look

| Task | Files |
| --- | --- |
| Game rules, names, sources | `site/data/*.json` (three files, 24 games each); schema in `research/SCHEMA.md` |
| Film animation of one game | `site/lessons-<family>.js` (large: search for the game ID, don't read whole) |
| Film look, timing, captions | `site/film-renderer.js`, `film-timeline.js`, `film-theme.js`, `tools/film-frame.mjs` |
| Player UI | `site/cinema.js`, `cinema.css`, `index.html` |
| Atlas, lineup, print, field guide | `site/atlas.*`, `dialogs.js`, `print.*`, `field-guide.*` |
| Making and checking films | `tools/render-films.mjs`, `tools/validate-*.mjs`; how-to in `docs/DEVELOPING.md` |

Don't read `site/films/` (binary films), `site/research-report.md` (generated) or `research/checks/` (machine records).

## Rules

- Films are generated. After changing a game's data or lesson, or any film code, re-render it (`npm run render-films -- --game=<id>`) and run `npm run check-films`; the manifest fingerprints must match.
- `site/research-report.md` is regenerated by `npm run report`; don't edit it by hand.
- Keep the browser storage keys (`gamessss-lineup-v1`, `gamessss-auto-next`, `gamessss-film-hint`) and the font name `GAMESSSS Symbols`: they're internal, and renaming them would wipe saved lineups or require re-rendering every film.
- No analytics, trackers or third-party requests.

## Commands

`npm start` (serve on :8879) · `npm run check` · `npm test` · `npm run check-films` (decodes every frame, ~2 minutes, needs ffmpeg)
